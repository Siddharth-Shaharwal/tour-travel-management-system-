# Frontend (Tailwind + Vite + React)

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

3. Make sure backend is running at http://localhost:4000 (or change .env VITE_API_BASE)

Notes:
- This project uses TailwindCSS. After npm install, Vite will build and serve the styles.
- If you see no data, ensure backend API is running and reachable.
